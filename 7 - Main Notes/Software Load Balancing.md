# Software Load Balancing

Applications that run on general-purpose servers or virtual machines.

- More affordable than hardware load balancers.
- Easily scaled by adding more resources or upgrading the underlying hardware.
- Lower performance compared to hardware load balancers, especially under heavy loads.
- Consume resources on the host system
